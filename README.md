# NEXLIFE AI — Future Simulator

A modern, interactive web application that helps you simulate and plan your possible future based on your goals, daily effort, and current resources.

## 🚀 Features

- **Goal Selection**: Choose from 5 different career paths (Singer, Business, Tech, Studies, Creator)
- **Personalized Scenarios**: Get a customized 12-month roadmap based on your effort level
- **Momentum Scoring**: Visual representation of your success probability (30 min/day = 55%, 1-2 hours = 72%, 3+ hours = 88%)
- **Beautiful UI**: Modern dark theme with cyan/purple gradient accents
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Client-side Processing**: All calculations happen in your browser—no backend needed

## 🎯 How It Works

1. **Choose a direction** - Select your primary goal
2. **Set your effort** - Decide how much time you can invest daily
3. **Explore scenarios** - See personalized milestones for 30 days, 3 months, 6 months, and 12 months
4. **Take action** - Use the simulation as a roadmap and adjust as your life changes

## 📋 Goal Categories

- **🎤 Singer**: Build vocal/guitar skills, create demos, grow audience
- **💰 Business**: Test products, track metrics, build stable revenue
- **💻 Tech**: Learn skills, build portfolio, gain experience
- **📚 Studies**: Improve weak topics, use active recall, boost performance
- **🎬 Creator**: Develop content theme, improve analytics, build audience
